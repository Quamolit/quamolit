# Raining 雨滴恢复：M3 #36 切片

推进 #36/#37。历史 `9b5bcdd` 的雨滴由逐帧 `rand` 生成，雨滴下落、触地展开成水花并消散。这里保留三段视觉行为，改用 Calcit `quamolit.examples.raining/scene-at (seed tick)` 生成确定帧。页面只管理时钟、URL、视口和 DOM；没有单独的 JS 粒子模拟器。

每秒 30 个整数 tick；384 个确定性槽位，每个槽位 180 tick 周期，错开出生。起点在旧版的 y=-400…-200，按约 100 单位/秒下落；到地面前 40 单位切换为每 tick 宽度 0–200、高度 0–6、透明度 0–0.5 的水花，越过 y=200 后消失。每轮由 seed、槽位和周期数计算水平位置，节点 ID 带周期数；水花变化由 seed、槽位和 tick 固定。因此同一 seed/tick 可直接乱序采样，重置和分享链接可重放；最多 384 个节点，不随运行时间增长。旧版逐帧约 30% 几率追加三滴、稳态可有上百滴；新密度在 seed 17 的固定帧约 260–275 滴，远比此前 48 槽位接近旧版。此运动有解析式，用固定 tick 采样即可，无需保存可变模拟状态或从 0 追帧；这不等于 #54 的 GPU 常驻历史模拟。

全屏 Canvas 使用 contain 的 1100 × 800 逻辑坐标，CSS 视口与 DPR backing store 分离。`?seed=17&tick=75` 为固定截图入口；播放只将宿主时间量化成 tick，暂停和 resize 不改变 tick。
