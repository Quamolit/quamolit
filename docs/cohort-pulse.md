# Cohort Pulse · 留存热力图

Cohort Pulse 是第三个偏 UI 的图表动画作品，用筛选列表、热力矩阵和详情面板验证声明式组件在真实分析界面中的进入、退出、重排与交叉渐变。它推进 [#146](https://github.com/Quamolit/quamolit/issues/146)，暂不关闭整个艺术作品工作项。

## 交互与状态

- 「全部群组 / 风险群组」由独立 `SwitchModel` 驱动。三个安全群组渐出并在终点卸载，三个风险群组保留原有 key、移动到新的行位置；42 个热力单元随父行运动，筛选终点只保留 21 个风险单元。
- 「组合摘要 / 事件详情」使用第二个 `SwitchModel`，两组面板节点交叉渐变。筛选与面板可以在任意中间时刻分别反向，不共享隐式宿主状态。
- 页面只管理逻辑时间、Canvas 尺寸、DOM 控件和 URL；`scene-at`、列表筛选、坐标、透明度与热力颜色均由 Calcit 直接采样。
- `?t=&filter=&panel=` 保存当前视觉位置，无需把完整事件日志写进链接。

## 固定画面

| 时间 / 操作  | 预期画面                                      |
| ------------ | --------------------------------------------- |
| `t=0`        | 舞台与标题已存在，矩阵行尚未进入              |
| `t=0.45`     | 行和热力单元按索引错峰进入                    |
| `t=0.9`      | 6 行、42 个单元与摘要面板完整显示             |
| 风险筛选 50% | 安全行淡出，风险行处于重排中点，稳定 key 不变 |
| 风险筛选终点 | 3 行、21 个单元；安全行已从 Scene 卸载        |
| 详情 50%     | 摘要与事件时间线同时存在并交叉渐变            |

## 检验

```bash
yarn test:cohort-pulse
QUAMOLIT_DEMO_TEST_PORT=5292 yarn test:demo-nav
```

Node 门禁验证乱序采样、稳定身份、中途反向、事件前缀分支、100 次面板往返与终点节点计数；浏览器门禁保存初始/中间/终点与移动端截图，并检查分享恢复、DPR 2、收起浮层和终点停帧。

当前使用 Canvas2D 参考绘制，不代表 WebGPU 路径、复杂文字排版或新性能目标已经完成。这个作品首先提供组件与动画语法证据，性能优化留给后续同源执行计划工作。
