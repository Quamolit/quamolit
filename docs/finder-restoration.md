# Finder 植物档案恢复：M3 #36/#37/#34 切片

历史 `9b5bcdd` 的 Finder 有五组植物文件夹，打开时居中放大，其他文件夹淡出；每组的中文卡片可以继续居中放大，其他卡片淡出，再逐层返回。本切片保留五组名称和卡片文本，以 Calcit `FinderModel` 中 5 条文件夹和 18 条卡片 `TransitionIntent` 分别保存每个稳定节点的目标，`scene-at (model time)` 生成 Scene 节点。页面每次绘制从同一Scene编译公共HitPlan，`hit-with-plan`命中实际已提交画面，不按点击瞬间的新宿主时间猜测另一份布局；事件记录在该画面时间，继续从可见姿态过渡。页面 JS 只管理宿主时间、DOM、URL 与 Canvas 坐标逆变换。

`append-event` 校验非降序点击日志，`replay` 在任意时间从日志重建 Model；历史时刻新输入先截断未来事件。`select-folder`、`select-card`、`back` 会同时重定向各节点自己的意图，因此上一文件夹或卡片尚未完全关闭时可以直接选择另一项，切换事件帧保持完整 Scene 相等，随后旧项退出与新项进入并行发生；连续 A→B→C 也不会丢掉仍在退出的 A。页面提供预设点击日志、手动点击、时间 seek 与包含日志的分享链接。桌面保留1100×800 contain构图，CSS宽度小于720px改用下述窄屏布局；全屏Canvas按视口和DPR更新实际像素，DOM控制浮层可收起。

## 窄屏布局 #128

`compact-document(document, width, height)`消费同次原Scene与显式CSS px视口：五组文件夹纵向排列，展开后的卡片两列排列；展开/聚焦进度从原矩形采样结果读取，颜色、alpha、文字、稳定身份与顺序保持原值，不修改Model或重采样动画。未聚焦卡片稳定帧保持18px文字，五组及18张卡片稳定帧均超过44×44px；进入退出过程中内容和字号继续跟随父级缩放，而非浮在父级外面。桌面不经过投影。

绘制与命中共用投影后的Scene。宿主Canvas backing store仍按DPR，窄屏CSS坐标1:1，事件按实际根变换逆变换；暂停resize只更新展示Scene与HitPlan，时间和输入意图不变。与#117采用相同显式CSS viewport合同，但不依赖尚未合并的TodoList接口；两种作品的布局不同，暂未硬抽出一个通用布局器。

短视口保留600px逻辑舞台，通过浮层“档案视窗”或Canvas滚轮浏览，不缩小字号/目标。Calcit的`compact-stage-height`、`compact-scroll-limit`、`compact-view-y`定义舞台高度、CSS滚动上限与根变换；滚动不写入输入日志、不推进时间、不修改Model。回到高视口自动收敛到0滚动；非法滚动值在修改状态前拒绝。聚焦时沿用当前视窗位置，短视口可能需滚动才能查看完整放大卡片；不承诺触屏拖动惯性。

已有门禁增加320×640、390×844、600×800五组/18卡片的字号、目标、父级几何与文字边界；DPR1/2逐张真实touch tap并返回，独立原生Canvas参考覆盖初始、展开、聚焦中间帧与终帧的全RGBA零差异，一像素错位负例必须失败。390×390还实际操作浮层滑块与滚轮、逐张进入全部卡片并验证全RGBA、非法输入与高/短视口切换不改意图；浮层视窗在不需要滚动时确实隐藏。截图进入既有Finder artifact。宽度低于300px仍按最低构图裁切，极小宽度、通用复用与触屏拖动待后续；投影重建Scene，不宣称布局缓存或性能提升，不提前关闭#128/M3。

卡片矩形和文字从同一个局部缩放比例计算字号与内边距。五组文件夹的初始、中间、聚焦帧均检查文字保持在父卡片内；视觉上不再像独立图层一样越界。

文件夹开合时，内部卡片的中心、宽高跟随文件夹展开值映射到场景坐标；完全闭合时保留不可见的极小正尺寸，以满足 Scene 校验。中间帧不会因只渐变透明度而露出文件夹边界。当前 Canvas 参考路径仍是平铺节点，尚不提供通用的父子裁剪语义，故以五组文件夹展开和收起的几何边界回归守住本示例。

当前是 Canvas2D 参考绘制，尚未接保留式组件计划或 WebGPU；并行动画使用固定 5/18 个小型意图，未作为大规模节点性能方案。真实页面复用公共命中；历史`hit-at`保留用于兼容与数值对照，但不参与实际页面点击。`hit-plan`仅调整原交互政策，不改提交Scene的几何、颜色或层序：关闭中其他文件夹仍可重开，卡片只在当前目标文件夹展开值大于0.05时参与命中，空白继续返回。Node覆盖五组、多时间乱序/打断的历史范围及移动/缩小反例；DPR1/2浏览器冻结rAF、单独前移宿主时钟验证不命中尚未绘制的新位置。这不是通用捕获或全链路索引优化，不关闭#34。窄屏已有上述布局及短视口浏览，公共复用与更小宽度仍见 [#128](https://github.com/Quamolit/quamolit/issues/128)，M3 不关闭。
