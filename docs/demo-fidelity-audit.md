# 原有 11 个 Demo 动画保真核对

历史基准是重构前最后一次提交 `9b5bcdd`（2024-04-01）的 `compact.cirru`，不是旧门户布局。以各组件声明的绘制内容、时序和输入行为为依据；仓库在 2024-04-01 到本轮重构之间没有更接近「一个月前」的旧版提交。核对当前全屏 Canvas 入口时，使用显式时间、事件日志或 seed，避免墙钟和随机截图造成误判。

| Demo | 历史效果与本轮核对 | 当前结论 / 继续检验 |
| --- | --- | --- |
| Binary Tree | 五层递归、两枝摆动和圆头连接；旧矩阵独立 oracle 逐边对照 126 条边。 | 构图与中间帧有数值和像素回归；GPU 合批不是此项保真门槛。 |
| TodoList | 行错峰进入/退出、完成变形、重排；浏览器查看 `?t=1.6` 时退出中的行仍可见。 | 核心过渡保留；编辑入口改为 DOM 浮层，字体/文本排版不与旧版逐像素相同。 |
| Clock | 六位七段、跨秒进位；旧 `comp-stroke` 的端点散开与蓝青/紫蓝切换曾遗漏。 | 本轮恢复 X ±120、Y ±160 范围的端点偏移、随透明度收拢和两种颜色；稳定 seed 取代挂载时随机，固定时间可复现。 |

| Icons | 旧版两块淡色方形底、实心绿色播放/暂停路径，以及旋转加号和交叉淡入数字；此前仅描边。 | 本轮恢复底色和两块实心路径；数字的逐帧重叠/坐标、画布内直接点击仍未做到与旧版完全等价。 |

本轮在 5190 本地 Vite 画面核对了各入口的固定帧；Curve、Solar、Clock、Icons、Raining 的视觉退化有源码依据与可重现的前后差异，因此优先修复。自动化测试不等于与 2024 年浏览器的逐像素等价：旧运行时和门户已不再作为可直接启动的对照环境。后续视觉验收应固定视口/DPR、时间或事件、seed，同时保存纯 Canvas 与含浮层截图；出现差异时先区分几何/时序/颜色/抗锯齿，再确定修复或记录独立 issue。

Curve/Solar 已完成原生路径核对；仍需跟进的保真项以 [#136](https://github.com/Quamolit/quamolit/issues/136) 的当前清单为准。原生 `arc!` 与 `bezier-curve-to!` 直接复用 js-ffi 的 Calcit 类型化 Canvas API，没有新增 JavaScript wrapper。不能因 11 个入口都能运行而自动判定为历史效果完全恢复；相关 Milestone #36/#37 仍按逐项证据关闭。
